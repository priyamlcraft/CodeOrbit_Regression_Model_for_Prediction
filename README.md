# CodeOrbit Task 3: Regression Model for Prediction

## Project Overview
This project builds a Machine Learning regression model using Python and Scikit-learn. It uses the Diabetes dataset to predict continuous target values with Linear Regression.

## Objectives
- Load and explore the dataset.
- Split data into training and testing sets.
- Train a Linear Regression model.
- Predict target values.
- Evaluate model performance.
- Visualize actual and predicted values.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
The project uses the Diabetes dataset provided by Scikit-learn for educational regression analysis.

## Project Workflow
1. Load the dataset.
2. Explore the data.
3. Split the dataset into training and testing sets.
4. Train a Linear Regression model.
5. Generate predictions.
6. Evaluate using MAE, MSE, RMSE, and R².
7. Plot actual versus predicted values.

## Installation
Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## How to Run
Run this command in the project folder:

```bash
python CodeOrbit_Task_3_Regression_Model_for_Prediction.py
```

## Evaluation Metrics
- **MAE:** Mean Absolute Error.
- **MSE:** Mean Squared Error.
- **RMSE:** Root Mean Squared Error.
- **R² Score:** Measures how well the model explains variation in the target values.

## Output
The program displays evaluation metrics and a comparison of actual and predicted values. It also saves a graph named `actual_vs_predicted.png`.

## Learning Outcomes
- Understanding regression in Machine Learning.
- Training a Linear Regression model.
- Making predictions using test data.
- Evaluating model performance.
- Visualizing prediction results.

## Conclusion
This project demonstrates a basic regression workflow using Python and Scikit-learn as part of the CodeOrbit Tech Machine Learning Internship.
